# real2sem2real.github.io

Project page for **Real2Sem2Real: 3D Semantic Augmentations for Robot Learning
from a Single Human RGB Demonstration**. Served by GitHub Pages at
https://real2sem2real.github.io from the `main` branch root.

- `index.html` is the whole site (no build step, no external dependencies).
- `static/img/` holds web renders of the paper figures. To refresh them after the
  paper's figures change, re-render from `semantics_paper_RAL/figures/` with
  Ghostscript (`gs -sDEVICE=png16m -r200 ...`; small charts at `-r480`).
- Author names, paper and code links are placeholders until the paper is public.
